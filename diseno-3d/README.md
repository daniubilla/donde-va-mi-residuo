Diseño 3D del sistema inteligente de clasificación de residuos, desarrollado en Autodesk Fusion 360. Incluye el modelo del basurero, su estructura, compartimentos y espacio para los componentes electrónicos.

## Diseño para mantenimiento y reparación

El modelo 3D contempla espacios diferenciados para los cuatro contenedores, el sistema de pesaje y los componentes electrónicos.

La distribución busca facilitar la inspección, el mantenimiento y el eventual reemplazo de componentes sin necesidad de reconstruir el sistema completo.

Las vistas interiores del modelo permiten identificar la ubicación de los principales elementos y analizar su accesibilidad.

La posibilidad de desmontaje y reparación deberá verificarse en el prototipo físico.
